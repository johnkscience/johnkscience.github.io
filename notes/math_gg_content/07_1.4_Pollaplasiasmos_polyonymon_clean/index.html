    Πολλαπλασιασμός πολυωνύμων

    Θεωρία

    1. Για να πολλαπλασιάσουμε ένα μονώνυμο με ένα πολυώνυμο χρησιμοποιούμε την επιμεριστική ιδιότητα \(\alpha \cdot (\beta +\gamma) = \alpha\beta + \alpha\gamma\), π.χ. \(3x^2\cdot (2x^3+6x)=(3x^2)\cdot (2x^3)+(3x^2)\cdot (6x)\)

    2. Για να πολλαπλασιάσουμε ένα πολυώνυμο με ένα άλλο πολυώνυμο χρησιμοποιούμε πάλι την επιμεριστική ιδιότητα \((\alpha +\beta )(\gamma + \delta ) = \alpha\gamma + \alpha\delta + \beta\gamma + \beta\delta\).

    3. Το αποτέλεσμα αυτών των πολλαπλασιασμών ονομάζεται ανάπτυγμα του γινομένου.

    4. Ο βαθμός του αποτελέσματος ισούται με το άθροισμα των βαθμών των δύο πολυωνύμων που πολλαπλασιάζουμε.

    Μάθημα 1

    1. Να βρείτε τα μονώνυμα από τα οποία αποτελούνται τα παρακάτω πολυώνυμα:

      1. \(3x^2+5x\)

      2. \(6x^3y+3x^2-3x+5\)

      3. \(-7xy^3+2xy^4-3x-5\)

      4. \(\sqrt{3}x^2-3\sqrt{5}x-6\)

    2. Αν \(P(x)=x^3+2x^2-6\) και \(Q(x)=2x^2-5\) να υπολογίσετε τον βαθμό του γινομένου \(P(x)\cdot Q(x)\). Μπορείτε να διατυπώσετε έναν κανόνα;

    3. Να κάνετε τις πράξεις:

      1. \(x\cdot (x+2x^2),\)

      2. \(-2x\cdot (x+y)\)

      3. \(2x^2\cdot (5x-2x)\)

      4. \(\sqrt{3}x\cdot (\sqrt 3x-x^2)\)

    4. Να κάνετε τις πράξεις:

      1. \((x+xy)\cdot x^2\)

      2. \((2x-3x^2+5)\cdot (-y)\)

      3. \((4x-3)\cdot xy^2\)

      4. \((\alpha +\beta )x\alpha ^2\)

    5. Να κάνετε τις πράξεις:

      1. \(3x(2xy+3x-5xy^2)\)

      2. \(\frac{1}{2}x(\frac{1}{3}x^2+\frac 1 5x)\)

      3. \(3x^3\cdot (\frac{1}{2}x-\sqrt{3}xy^2)\)

      4. \(\frac 1{\sqrt 3}xy\cdot (\frac{\sqrt{3}} 3xy^2-5+6x)\)

    6. Να κάνετε τις πράξεις:

      1. \(x\cdot (y^2)\cdot (x+y)\)

      2. \((xy^2)\cdot (x^3)\cdot (x^2+2xy)\)

      3. \((-x)\cdot (-2x^2)\cdot (x^2-3x^2y)\)

      4. \(x\cdot (x+y)\cdot y\)

      5. \((x+y)\cdot x\cdot y\)

    7. Να γίνουν οι πράξεις:

      1. \((x+2)(x-1)\)

      2. \((x-2)(x+2)\)

      3. \((3-x)(x+3)\)

      4. \((-2-x^2)(-x-5)\)

    8. Να γίνουν οι πράξεις:

      1. \((x+2)(2x-3+y)\)

      2. \((-x+4)(2xy^2-3xy+6)\)

      3. \((x+2)(x^2+x-3)\)

      4. \((x+2x-x^2)(x-3)\)

    9. Να γίνουν οι πράξεις:

      1. \((x^2+2x-3)(3x^2-4x+2)\)

      2. \((x^2+2x-3)(x^2+2x-3)\)

    10. Να κάνετε τις πράξεις:

      1. \(2(x-3)+4(x-5)\)

      2. \(2x(x-3)+4x(x-5)\)

      3. \(2x^2(x^2-3)+4x(x^2-5x+3)\)

      4. \(2x(x^2+x)-2x(x^2-2x)+6(x-2)\)

    Μάθημα 2

    1. Να γίνουν οι πράξεις.

      1. \(-\frac 2 3x^2y(x-\frac{1}{3}y-3)\)

      2. \((2x^2-5x+6)(x-2)\)

      3. \(4x(-2x^2+3x-1)-3x^2(-2x+5)\)

      4. \(-2x^2(x+4)(x-1)\)

    2. Να γίνουν οι πράξεις:

      1. \(x(x+1)\)

      2. \((x+1)(x-1)\)

      3. \(x(x-1)\)

      4. \((x+1)(1+x)\)

      5. \((x+1)(x+2)\)

    3. Να χαρακτηρίσετε τις παρακάτω προτάσεις με Σ αν είναι σωστές ή με Λ αν είναι λανθασμένες.

      1. Αν το πολυώνυμο P(x) έχει βαθμό 3 και το πολυώνυμο Q(x) έχει βαθμό 2, τότε το πολυώνυμο \(P(x)\cdot Q(x)\) έχει βαθμό 6

      2. Αν το πολυώνυμο \(P(x)\cdot Q(x)\) έχει βαθμό 7 και το πολυώνυμο P(x) έχει βαθμό 3 τότε το πολυώνυμο Q(x) έχει βαθμό 4

    4. Να κάνετε τις πράξεις:

      1. \(-3x^2y(-5x+2y)\)

      2. \(4x(2x^2-x+2)-8x\)

      3. \(-5x(2x-3)-3x(2-3x)\)

      4. \(2xy(x^2-3y^2)-4x(x^2y-2y^3)\)

    5. Nα κάνετε τις πράξεις:

      1. \((2\alpha -3\beta )(-4\alpha +2\beta )\)

      2. \((x^2-2x+4)(x+2)-8\)

      3. \(3x^2(-2x+3)(5-x)\)

      4. \((4-3x)(5-2x)-6x(x-4)\)

      5. \((2x^2-3x-4)(-3x^2+x)\)

      6. \((3x^2-2xy-5y^2)(4y-x)\)

    6. Να κάνετε τις πράξεις:

      1. \((3x-2)(x^2-x)(4x-3)\)

      2. \(-2x(x^2-x+1)(x-2) - (x-1)(2x-3)(x+2)\)

      3. \((-2x+y)(x^2-3xy) - (3x-y)(4x+y)(-2x-3y)\)

    7. Να γίνουν οι πράξεις:

      1. \((x^2-2y)3y + (xy-y^2)(-x) + (x+y)(-2xy)\)

      2. \(2[4(x-y)-2(3x+y)] + 2[3(x^2-xy+y^2)-(x^2-y)]\)

      3. \(2[2(x-y)-3(x-2y)] - 4[3(x^2-y^2)+7xy-(x^2-y)]\)

      4. \((x+y)(y+z) - (z+\omega)(\omega+x) - (x+z)(y-\omega)\)

    8. Να κάνετε τις πράξεις:

      1. \((x+y)^2\)

      2. \((x-y)^2\)

      3. \((x-y)(x+y)\)

      4. \((x+y)^3\)

      5. \((x-y)^3\)

    9. Να αποδείξετε ότι το πολυώνυμο: \(P(x)=(x+2)^2-2(x-1)^2-4(x+1)^2+5x^2\) είναι το μηδενικό.

    10. Δίνονται τα πολυώνυμα \(f(x)=x+2\) και \(g(x)=x-2\). Να υπολογίσετε τις παραστάσεις:

      1. \(g(x)\cdot f(x)\)

      2. \(^2\)

      3. \(^2\)

      4. \(f(x+1)\)

      5. \(g(-x)\)

      6. \(f(x+1)\cdot g(x+1)\)

      7. \(f(-x)\cdot g(-x)\)

    Μάθημα 3

    1. Χρησιμοποιώντας την επιμεριστική ιδιότητα \(ax+ay=a(x+y)\) να κάνετε τις πράξεις:

      1. \(\alpha x+ay\)

      2. \(xy+xa^2\)

      3. \(x^2y+x^2a^2\)

    2. Να απλοποιήσετε τις παραστάσεις απαλείφοντας τις παρενθέσεις:

      1. \(-(x^2+y^2-3x-5)\)

      2. \(-(2x-3)-(x^2-2x)\)

    3. Αν \(P(x)=-2x^2+5x-3\) και \(Q(x)=4x-5\), να βρείτε τα πολυώνυμα:

      1. \(P(x)\cdot Q(x)\)

      2. \(P(x)\cdot [-3Q(x)+11x-12]\)

      3. \(\cdot [Q(x)+3]\)

    4. Ένα ορθογώνιο έχει πλευρές \(P(x)=-2x^2+5x-3\) και \(Q(x)=4x-5\) , να βρείτε:

      1. το εμβαδόν του

      2. την περίμετρό του.

    5. Αν \(P(x)=3x(-2x+4)(x-1)\) και \(Q(x)=\alpha x^3+\beta x^2+\gamma x+\delta\), να βρείτε τις τιμές των α, β, γ, δ, ώστε τα πολυώνυμα Ρ(x) και Q(x) να είναι ίσα.

    6. Αν \(f(x)=x-2\), \(g(x)=2x-3\) και \(h(x)=1-x\) να υπολογίσετε τις παραστάσεις:

      1. \(f(x)\cdot g(x)\cdot h(x)\)

      2. \(\cdot h(x)\)

      3. \(2[3g(-x)-4f(x+1)]-3h(-x+2)\)

    7. Δίνεται το πολυώνυμο \(f(x)=x^2\) να υπολογίσετε:

      1. f(0),

      2. f(1), f(-1),

      3. f(2), f(-2)

      4. f(3), f(-3)

      5. Ποια νομίζετε ότι είναι η μικρότερη τιμή που παίρνει αυτό το πολυώνυμο;

      6. Ποια νομίζετε ότι είναι η μεγαλύτερη τιμή που παίρνει αυτό το πολυώνυμο;

    8. Δίνεται το πολυώνυμο \(f(x)=16-x^2\) να υπολογίσετε:

      1. f(0),

      2. f(1), f(-1),

      3. f(2), f(-2)

      4. f(3), f(-3)

      5. Ποια νομίζετε ότι είναι η μικρότερη τιμή που παίρνει αυτό το πολυώνυμο;

      6. Ποια νομίζετε ότι είναι η μεγαλύτερη τιμή που παίρνει αυτό το πολυώνυμο;

    9. Να αποδείξετε ότι το πολυώνυμο \(p(x)=(2x+3)^2-(2x+1)^2\) είναι πολλαπλάσιο του 8.

    10. Να αποδείξετε ότι η παράσταση: \((x+3y)^2+(x-3z)^2-3(x+y+z)^2+(x^2+y^2+z^2)\) είναι ανεξάρτητη του x

    Κριτήριο 1

    1. Αν \(P(x)=x^3+2x^2-6\) και \(Q(x)=2x^2-5\) να υπολογίσετε τον βαθμό του γινομένου \(P(x)\cdot Q(x)\) . Μπορείτε να διατυπώσετε έναν κανόνα;

    2. Να γίνουν οι πράξεις:

      1. \((x+2)(x-1)\)

      2. \((x-2)(x+2)\)

      3. \((3-x)(x+3)\)

      4. \((-2-x^2)(-x-5)\)

    3. Να γίνουν οι πράξεις:

      1. \((x^2-2y)3y+(xy-y^2)(-x)+(x+y)(-2xy)\)

      2. \(2[4(x-y)-2(3x+y)]+2[3(x^2-xy+y^2)-(x^2-y)]\)

      3. \(2[2(x-y)-3(x-2y)]-4[3(x^2-y^2)+7xy-(x^2-y)]\)

      4. \((x+y)(y+z)-(z+\omega )(\omega +x)-(x+z)(y-\omega )\)

    4. Δίνονται τα πολυώνυμα \(f(x)=x+2\) και \(g(x)=x-2\) . Να υπολογίσετε τις παραστάσεις:

      1. \(g(x)\cdot f(x)\)

      2. \(^2\)

      3. \(^2\)

      4. \(f(x+1)\)

      5. \(g(-x)\)

      6. \(f(x+1)\cdot g(x+1)\)
