1. Βασικές Πράξεις και Έννοιες

Μάθημα 5 – Κλάσματα

Τι ονομάζουμε κλάσμα;
Να απαντήσετε στις παρακάτω ερωτήσεις:
  1. Πως γίνεται ο πολλαπλασιασμός δύο κλασμάτων;
  2. Πως γίνεται η διαίρεση δύο κλασμάτων;
  3. Πως γίνεται η πρόσθεση και η αφαίρεση δύο κλασμάτων
Να βρείτε το πρόσημο των παρακάτω κλασμάτων:
  1. `+ (2 / 3)`, `2 / 3`, `-(2 / 3)`, `((-2)) / 3`, `2 / (-3)`
  2. `-((-2) / 3)`, `- (2 / (-3))`, `- ((-2) / (-3))`, `(-2) / (-3)`
Να κάνετε τους πολλαπλασιασμούς:
  1. `(2 / 3) cdot (4 / 5)`, `2 cdot (2 / 3)`, `(2 / 3) (-2)`
  2. `((-2) / 4) cdot (4 / 7)`, `(1 / 2 ) cdot (2 / 1)`, `0 / 3 cdot 3`, `(1 / 3) cdot 0 `
Μπορούμε να διαιρέσουμε με το μηδέν;
Να κάνετε τις διαιρέσεις:
  1. `(2 / 3) : (4 / 5)`, `((-2) / 4) : (4 / 7)`,
  2. `(2 / 3) / (4 / 5)`, `(2 / 3): 4`, `(2 / 3) / (4)`, `4 : (2 / 3)`, `4 / ( 2 / 3)`
Ποιοι από τους παρακάτω αριθμούς μπορούν να γραφούν με την μορφή κλάσματος ή είναι ήδη κλάσματα: `-1`, `0`, `1`, `1.34`, `2.bar(3)`.
Να βρείτε το ΕΚΠ και τον ΜΚΔ των παρακάτω αριθμών:
  1. `(2, 3)`
  2. `(3, 15)`
  3. `(3,4,5)`
  4. `(3,7,11)`
  5. `(2022, 4200, 1240)`
Να κάνετε τις προσθέσεις:
  1. `(2 / 3) + (4 / 5)`, `((-2) / 4) + (4 / 7)`, `((-2) / (3)) + ((-1) / (5))`
  2. `(2 / (-3))+((-2) / 3)`, `- ((-2) / (-3))+((-3) / (-5))`
  3. `1-(1 / 2)+ (1 / 3)-(1 / 4)`
Πως γίνεται η απλοποίηση ενός κλάσματος και τι είναι το ανάγωγο κλάσμα;
Να απλοποιήσετε τα παρακάτω κλάσματα: `15 / 25`, `345 / 25`, `21 / 7`, `6 / 3`, `3 / 6`, `8 / 4`, `4 / 8`
Να κάνετε τις πράξεις με την σωστή σειρά:
  1. `- ((-2) / 3) : 3 / 2 + (-( (-2 / 3)+ (4 / 5))-1) / (2-((-(3 / 4)) cdot ( 5 / 2)))`,
  2. `( -1 ) / (3-(1/ (3- (1 / 5))))`
Να κάνετε τις πράξεις με την βοήθεια της επιμεριστικής ιδιότητας.
  1. `-2( -(3/ 4) +(4 / 5))`,
  2. `2( 4 / 3 -3 / 5 -2 / 7)`
  3. `(-2/3 -3/5) 3`
  4. `(-2/3 -1/5)(3/4 -1/2)`
Εάν οι διαστάσεις ενός ορθογωνίου είναι `2 / 3` και `2 / 5` να υπολογίσετε το εμβαδόν και την περίμετρο του.
