1. Βασικές Πράξεις και Έννοιες

Μάθημα 2 – Βασικές Πράξεις

Να απαντήσετε στις παρακάτω ερωτήσεις:
  1. Τι ονομάζουμε απόλυτη τιμή;
  2. Τι πρόσημο έχει η απόλυτη τιμή;
  3. Ποιοι είναι οι αντίθετοι αριθμοί;
  4. Ποιοι είναι οι ετερόσημοι αριθμοί;
Να κάνετε τις πράξεις:
  1. `abs(-2)`
  2. `abs(-2 +4)`
  3. `-2+abs( -2)`
  4. `-abs( -2 -1)`
Να κάνετε τις πράξεις:
  1. `-2 cdot abs(-2)-(-2)cdot (-3)`,
  2. `-3 cdot(-3) + (abs(-2)) -1`,
  3. `-2 cdot (-2 -3 +4)`,
  4. `-4 cdot ( -2 cdot (abs( -3)) -2)`
Να κάνετε τις πράξεις:
  1. `-[-2 – 3( -3 +4 cdot 2) -2] – 2`,
  2. `2-[ -3 cdot (-4) - (-2) -1] +5`,
  3. `(-1)cdot (-1)`,
  4. `(-1) cdot (-1) cdot(-1)`,
  5. `(-1) cdot (-1) cdot (-1) cdot (-1)`
Να κάνετε τις πράξεις:
  1. `(1 / 2) + (3 / 4)+1`,
  2. `(2 / (-4)) - ((-5) / (-4))`
Να κάνετε τις πράξεις:
  1. `(1 / 2) - (-3 / 4)`,
  2. `-1 / -2 – 3 / -5`
  3. `-2 cdot ( -2 / 3 – 4 / 2 )`
Να κάνετε τις πράξεις.
  1. `2 / 3 : 3 / 2`,
  2. `2 / 3 : 3`
  3. `3 : 2 / 3`
Να κάνετε τις πράξεις.
  1. `3: 3 / (2-1)`,
  2. `3 / (5-3) : (4-5) / (6-1)`,
  3. `(4 / (4-6)) cdot ((3-5) / 8)`
Να κάνετε τις πράξεις.
  1. `(( 3 / 4 : 4 / 5) / (2 / 3 : 2 / 5)) + ( ( 2 / 3 + 3 / 2 ): ( 1 / 2 ) )/( 3 / 4 : ( - (1 / 2) ) )`
Να τοποθετήσετε πάνω στην ευθεία των πραγματικών αριθμών τους παρακάτω αριθμούς. `1`, `-1`, `2`, `3 / 4`, `4 / 3`, `abs(-2)`, `-2`, `3 / 4 : 3 / 4`
Ποιο είναι το πρόσημο του αποτελέσματος της απόλυτης τιμής;
Αν `abs(x)=2` να βρείτε ποιος αριθμός/μοι μπορεί να είναι το x.
Αν `abs(x)=-2` να βρείτε ποιος αριθμός/μοι μπορεί να είναι το x.
