5. Ρίζες Θετικών Αριθμών

Μάθημα 2 – Βασικές Πράξεις

Να υπολογίσετε τις τετραγωνικές ρίζες:
  1. `sqrt 36`, `sqrt 3600`, `sqrt 0.36`
  2. `sqrt 144`, `sqrt 1.44`, `sqrt 14400`, `sqrt 0.000144`
Να απλοποιήσετε τις παραστάσεις
  1. `{:sqrt 4:}^2`
  2. `sqrt {:7^2:}`
  3. `sqrt {:(-6)^2:}`
Να υπολογίσετε τις τετραγωνικές ρίζες:
  1. `sqrt {:36 / 9:}`
  2. `sqrt {:400 / 144:}`
  3. `sqrt {:36 / 121:}`
Ποιες από τις παρακάτω προτάσεις είναι σωστές;
  1. `sqrt {:α cdot β:} = sqrt α cdot sqrt β`
  2. `sqrt {: α / β :} = {:sqrt α :}/{: sqrt β:}`
  3. `sqrt {:α+β:} = sqrt α + sqrt β`
  4. `sqrt {:α -β:} = sqrt α - sqrt β`
Να κάνετε τις πράξεις:
  1. `sqrt 625 / sqrt 225 - sqrt 169`
  2. `sqrt 25 cdot {:1 / 5:} - 6 cdot {: 1 / sqrt 36:}`
Κάνετε τις πράξεις:
  1. `sqrt sqrt sqrt 256`
  2. `sqrt {: 2 + sqrt 4:}`
  3. `sqrt{: 8 + sqrt 64:} - sqrt {: 1 + sqrt 9:}`
Να βρείτε τις δύο λύσεις των παρακάτω εξισώσεων:
  1. `x ^2 =16`
  2. `α^2 = 256`
  3. `α^2= 49`
Αφού κάνετε τις πράξεις να διατάξετε τους αριθμούς `α^2, α, sqrt α` στις παρακάτω περιπτώσεις
  1. α=4
  2. α=9
  3. α=16
Τι παρατηρείτε;
Αφού κάνετε τις πράξεις να διατάξετε τους αριθμούς `α^2, α, sqrt α` στις παρακάτω περιπτώσεις
  1. `α=1 / 4`
  2. `α= 1 / 9`
  3. `α=1 / 16`
Τι παρατηρείτε;
Αφού κάνετε τις πράξεις να διατάξετε τους αριθμούς `α^2, α, sqrt α` στις παρακάτω περιπτώσεις
  1. α=0
  2. α=1
Τι παρατηρείτε;
Να υπολογίστε την άγνωστη πλευρά των παρακάτω ορθογωνίων τριγώνων:
Αν `α`, `β`, `γ` είναι οι πλευρές ενός ορθογωνίου τριγώνου `ΑΒΓ` με `hat Α=90^ο`, αν λάβετε υπόψιν ότι απέναντι από την γωνία `hat Α ` είναι η πλευρά ` α`, να υπολογίσετε την πλευρά που λείπει.
  1. `α=5, β= x, γ=3`
  2. `α= x, β=5, γ=12`
  3. `α=37 / 2, β= x , γ=35 / 2`
  4. `α=25, β=7, γ= x `
  5. `α= x , β=40, γ=9`
  6. `α=61, β= x , γ=11`
  7. `α=25, β=7, γ= x `
Να επιλέξετε τις σωστές απαντήσεις. Ενώ όποιες είναι λανθασμένες να τις διορθώσετε Σε ένα ισοσκελές τρίγωνο:
  1. και οι τρεις πλευρές είναι ίσες
  2. βάση ονομάζεται αυτή που ακουμπάει στο έδαφος
  3. οι γωνίες που πρόσκεινται στην βάση είναι ίσες με 45 μοίρες
  4. και οι τρεις γωνίες του τριγώνου είναι ίσες
  5. το ύψος είναι και διάμεσος και διχοτόμος
Να επιλέξετε τις σωστές απαντήσεις. Ενώ όποιες είναι λανθασμένες να τις διορθώσετε Σε ένα ορθογώνιο τρίγωνο:
  1. οι δύο γωνίες είναι ίσες με 90 μοίρες η κάθε μία,
  2. έχει δύο πλευρές ίσες,
  3. η μεγαλύτερη πλευρά ονομάζεται υποτείνουσα και οι άλλες δύο κάθετες,
  4. ισχύει το Πυθαγόρειο θεώρημα,
  5. μπορεί να είναι ισοσκελές
  6. μπορεί να είναι ισόπλευρο
  7. Όλες οι γωνίες του έχουν άθροισμα ίσο με 180 μοίρες.
