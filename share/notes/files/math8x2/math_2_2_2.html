2. Δυνάμεις Πραγματικών Αριθμών

Μάθημα 1 – Ορισμός και ιδιότητες

Να απαντήσετε στις παρακάτω ερωτήσεις:
  1. Πώς ορίζονται οι δυνάμεις;
  2. Να γράψετε τις ιδιότητες των δυνάμεων.
Να κάνετε τις πράξεις:
  1. `2^0`, `2^1`, `2^3`, `2^4`
  2. `1^0`, `1^1`, `1^2`, `1^3`, `1^4`
  3. `0^1`, `0^2`, `0^3`, `0^4`
  4. `3^0`, `3^1`, `3^2`, `3^3`
  5. `4^0`, `4^1`, `4^2`, `4^3`
  6. `5^0`, `5^1`, `5^2`, `5^3`
Να κάνετε τις πράξεις:
  1. `(-1)^0`, `(-1)^1`, `(-1)^2`, `(-1)^3`
  2. `(-2)^0`, `(-2)^1`, `(-2)^3`
  3. `(-3)^0`, `(-3)^1`, `(-3)^2`, `(-3)^3`
  4. `(-5)^0`, `(-5)^1`, `(-5)^2`, `(-5)^3`
Ορίζετε η πράξη `0^0`;
Να κάνετε τις πράξεις:
  1. `2^(-1)`, `2^(-2)`, `2^(-3)`, `2^(-4)`
  2. `3^(-1)`, `3^(-2)`, `3^(-3)`, `3^(-4)`
  3. `1^(-1)`, `1^(-2)`, `1^(-3)`, `1^(-4)`
Να κάνετε τις πράξεις:
  1. `(-2)^(-1)`, `(-2)^(-2)`, `(-2)^(-3)`
  2. `(-3)^(-1)`, `(-3)^(-2)`, `(-3)^(-3)`
  3. `(-1)^(-1)`, `(-1)^(-2)`, `(-1)^(-4)`
  4. `-2^0`, `-2^1`, `-2^2`, `-2^3`, `-2^4`
Να κάνετε τις πράξεις:
  1. ` ( 3 / 2 ) ^0`, ` ( 3 / 2 ) ^1`, ` ( 3 / 2 ) ^2`, ` ( 3 / 2 ) ^3`
  2. ` ( 3 / 2 ) ^( -1 )`, ` ( 3 / 2 ) ^( -2 )`, ` ( 3 / 2 ) ^( -3 )`, ` ( 3 / 2 ) ^( -4 )`
  3. ` ( -3 / 2 ) ^( -1 )`, ` ( -(3 / 2) ) ^( -2 )`, ` ( 3 / (-2) ) ^( -3 )`
Να κάνετε τις πράξεις:
  1. `2^3 cdot 2^4`
  2. `2^2 cdot 2^6 cdot 2^3`
  3. `2^(-2) cdot 2^2`
  4. `2^(-3) cdot 2^5`
  5. `2^(-3) cdot 2^(-5)`
Να κάνετε τις πράξεις:
  1. `2^3 : 2^4`
  2. `2^2 : 2^6 `
  3. `2^(-2) : 2^2`
  4. `2^(-3) : 2^5`
  5. `2^(-3) : 2^(-5)`
Να κάνετε τις πράξεις:
  1. `2^3 / 2^4`
  2. `2^2 / 2^6 `
  3. `2^(-2) / 2^2`
  4. `2^(-3) / 2^5`
  5. `2^(-3) / 2^(-5)`
Να κάνετε τις πράξεις:
  1. `2^3 cdot 3^3`
  2. `3^2 cdot 4^2`
  3. `5^2 cdot 2 ^2`
  4. `(-2)^3 cdot (1 / 2)^3`
Να κάνετε τις πράξεις:
  1. `2^3 : 3^3`
  2. `3^2 : 4^2`
  3. `5^2 : 2 ^2`
  4. `(-2)^3 : (1 / 2)^3`
Να κάνετε τις πράξεις:
  1. `2^3 / 3^3`
  2. `3^2 / 4^2`
  3. `5^2 / 2 ^2`
Να κάνετε τις πράξεις:
  1. `(2^2)^3`
  2. `(3^3)^(-2)`
  3. `((-2)^2)^3`
  4. `(-2^2)^3`
