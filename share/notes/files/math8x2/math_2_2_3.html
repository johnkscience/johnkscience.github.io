2. Δυνάμεις Πραγματικών Αριθμών

Μάθημα 2 – Ορισμός και ιδιότητες

Να απαντήσετε στις παρακάτω ερωτήσεις:
  1. Πότε οι δυνάμεις `(-x)^n` και `-x^n` είναι ίσες;
  2. Υπάρχουν ιδιότητες των δυνάμεων για την πρόσθεση και την αφαίρεση;
  3. Εάν οι βάσεις και οι εκθέτες είναι διαφορετικοί μπορούμε να εφαρμόσουμε κάποια ιδιότητα;
Να κάνετε τις πράξεις:
  1. `2 cdot 3 ^2 -10`
  2. `4^2 – 2^3 cdot 3`
  3. `2 cdot 3 - (-2) cdot 4^2 – 6 cdot (-2)`
  4. `4:8 – 3^2:3`
Να κάνετε τις πράξεις:
  1. `(2 -1)^2`
  2. `-(2 -1)^2`
  3. `-2 cdot ( -1 +2)^7`
Να κάνετε τις πράξεις:
  1. `(-2)^2 cdot (-3)+2 cdot 3^2-5^2 cdot ( -2 ) : 5 -6`
  2. `(-3) cdot (-2)^2-( -2)^3 +4^2:16 -1`
  3. `-[ -( -2 +3)^2 -1]^2 +2`
Να κάνετε τις πράξεις:
  1. `((1 / 2))^2 - 3 cdot (-(1 / 3)+(2 / 6))^2`
  2. `(-(4 / 3)) cdot ( (4 / 6))^2+(3 / 6)`
  3. `-5 cdot ( - (- (3 / 2))^3)+(4 / 2) : (5 / 4)`
Υπολογίστε:
  1. `((-3)^2 cdot 2^2+2 cdot 3^2:2) / (-2^2-3^2-(-2)^2) +3`,
  2. `((-2)^2-2^2+3) / (3 cdot (-3 +4)^2 cdot ((-3^3+3^3-4) / (2 cdot 4+3^2)))`
Να διαλέξετε την σωστή απάντηση στην επόμενη πρόταση. Η τιμή (αποτέλεσμα) της σχέσης `0^(-3)` είναι:
  1. 1
  2. -1
  3. 0
  4. κάποιος άλλος πραγματικός αριθμός που μπορώ να υπολογίσω
  5. η τιμή αυτής της σχέσης δεν ορίζεται αφού προκύπτει διαίρεση με το μηδέν.
Αφού κάνετε τις πράξεις να γράψετε τι παρατηρείτε:
  1. `(3+4)^2`, `3^2+4^2`, `3^2+4^2+2 cdot 3 cdot 4`
  2. `(1+3)^2`, `1^2+3^2`, `1^2+3^2+2 cdot 1 cdot 3`
  3. `(3-4)^2`, `3^2-4^2`, `3^2 + 4^2-2 cdot 3 cdot 4`
  4. `(1-3)^2`, `1^2-3^2`, `1^2+3^2-2 cdot 1 cdot 3`
Να χαρακτηρίσετε τις παρακάτω προτάσεις με (Σ), αν είναι σωστές ή με (Λ), αν είναι λανθασμένες:
  1. Για κάθε αριθμό α ισχύει `α + α + α + α = α^4`.
  2. Για κάθε αριθμό α ισχύει `α cdot α cdot α cdot α = α^4`.
  3. Οι αριθμοί `(–5)^6` και `–5^6` είναι αντίθετοι.
  4. Οι αριθμοί `( 2 / 3 )^8` και `( 3 / 2 )^8` είναι αντίστροφοι.
  5. Για κάθε αριθμό α ισχύει `(3α)^2 = 9α^2`.
  6. Ο αριθμός `–(– 5)^2` είναι θετικός.
  7. Ο αριθμός `2^2+3^2` είναι ίσος με τον `(2+3)^2`
  8. `(-1)^2023=-1`
  9. `(-1)^2024=1`
Να αντιστοιχίσετε τα στοιχεία της πρώτης στήλης με αυτά της δεύτερης.
Στήλη Α Στήλη Β
(α) `(2^4)^(-1)` (1) `1 / 4`
(β) `(2^(-5))^2 cdot 2^10` (2) `-2^4`
(γ) `(-2)^(-2)` (3) 4
(δ) `(2^4 : 2^3) cdot 2^2` (4) `2^3`
(5) `2^(-4)`
(6) 1
Να κάνετε τις πράξεις:
  1. `10^0`, `10^1`, `10^2`, `10^3`
  2. `10^(-1)`, `10^(-2)`, `10^(-3)`
