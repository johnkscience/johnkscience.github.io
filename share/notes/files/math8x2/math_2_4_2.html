4. Εξισώσεις 1ου Βαθμού

Μάθημα 1 – Βασικές Έννοιες

Να απαντήσετε στις παρακάτω ερωτήσεις:
  1. Τι ονομάζουμε εξίσωση πρώτου βαθμού με έναν άγνωστο;
  2. Πόσα μέλη έχει μια εξίσωση;
  3. Τι είναι ο άγνωστος;
  4. Τι πρέπει να κάνουμε όταν μας ζητάνε να λύσουμε μια εξίσωση;
  5. Τι ονομάζουμε ρίζα μιας εξίσωσης;
  6. Πότε μια εξίσωση είναι αδύνατη και πότε είναι ταυτότητα;
  7. Ποιες είναι οι τέσσερις πράξεις που μπορούμε να εφαρμόσουμε σε μια εξίσωση;
Ποιες από τις παρακάτω είναι εξισώσεις;
  1. `2 x + 5=9`
  2. `4x^2 +5x`
  3. `4x^2 +5x +3 =0`
Ποιες από τις παρακάτω εξισώσεις είναι πρώτου βαθμού;
  1. `2x+4x-5=3x-9`
  2. `5x^2+3x-3=9-2x`
  3. `2(x-3)+4x=0`
  4. `{:2(x-1):} / 3+ x / 6=1 / 2`
  5. `x(x-2)=0`
Ποιες από τις παρακάτω εξισώσεις είναι με έναν άγνωστο;
  1. `2α+β=0`
  2. `2α+6=3α-1`
  3. `5x+6y=9`
  4. `2x^2+5x-6=0`
  5. `(x-4)(y-4)=0`
  6. `x^2+y^2=0`
  7. `2x-2+4x=4x`
  8. `15x +2 =0`
Να λύστε τις παρακάτω εξισώσεις:
  1. `2x+6=5x-3`
  2. `7x+8x-9=10x-10+12`
  3. `-13-x-3=0`
  4. `-x -3x -6 =4x +8`
  5. `10x -23 = 2x -23`
Να λύσετε:
  1. `-x= 10`
  2. `-x = -2`
  3. `-x =0`
  4. `2x =0`
Να λύσετε:
  1. `3(x+4)-(x-2)=2+2x`
  2. `4-(7x+5)=12-2x`
  3. `2(x-3) -4(2x -5)=3( -2x+5)`
  4. `4x(4 -6) -3 ( -2x -1) =0`
Να λύσετε:
  1. `10x -2( 4 +5x) = -8`
  2. `8x - 2(4+4x)=8`
  3. `7x-2[3(1-x)]=-(7 -13x)`
  4. `6x -\{: 4 -3[2x+5(x -1)]\:}=62`
Να λύσετε:
  1. `{:2x-3:} / 4 = {:3x-2:} / 8`
  2. `{:3x -5:} / 3 = x / 7`
  3. `{:3x:} / 4 = x / 6`
  4. `{:3x:} / 5 =6`
  5. `x / 5 =10`
  6. `x / 6 = 1 -x / 3`
  7. `x / 6 = x / 5`
Να λύσετε:
