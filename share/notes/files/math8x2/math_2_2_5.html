2. Δυνάμεις Πραγματικών Αριθμών

Μάθημα 4 – Πράξεις

Να απαντήσετε στις παρακάτω ερωτήσεις:
  1. Ποια είναι η προτεραιότητα των πράξεων;
  2. Ποια πράξη ( η διαίρεση ή η πρόσθεση) έχει προτεραιότητα στην έκφραση: `{:2+3:} / {:5 +6:}` και γιατί;
Να κάνετε τις πράξεις με την σειρά που πρέπει:
  1. `2 cdot (-3)`
  2. `2+ (-3)`
  3. `2 cdot 3 – 4 cdot 5`
  4. `2^3 cdot 4`
  5. `2^3 +4`
  6. `2^3 - 5`
  7. `2^3 : 8`
  8. `2^3 / 2`
Να κάνετε τις πράξεις:
  1. `(2-3)^2`
  2. `(2-3 cdot 2)-2^3`
  3. `2^4-( -2 -3 cdot ( -2))+1`
  4. `(2^2 cdot 3 – 4 : 2^2)-5^2`
  5. `2 cdot 3 + 5 cdot (-1)^3 - (-2 cdot 3 -2)^2`
Να κάνετε τις πράξεις:
  1. `{:-2 cdot (-3)+3^2:} / {:2 cdot 3 -4:}`
  2. `{:-4 - ( -2 -3)+ 2^2 cdot 3:} /{: -( -4 +5):}`
  3. `{:-2^2+3 cdot (-2)^2:} / {:1+ 5 cdot (-2)^3:}`
  4. `{:-( -2 +3)^2001 +2021^0:} / {:0^2023+1:}`
  5. `{:1-1:2:} / {:1 + 1:2:}`
Να κάνετε τις πράξεις:
  1. `[ (- {:1 / 2:})^-2 ]^-4 : [ (- {:1 / 2:})^5 ] ^{:-4:}`
  2. `{:[-3^{:-2:}]^3[(-9)^{:-2:}]:} / {:(-9)^3(-3)^2:}`
Υπολογίστε:
  1. `{:1 – 3 cdot ( 2 / 3)^0 :} / {:-2:}`
  2. `{:2^{:-3:}+(3 / 4)^{:-4:} cdot (-1 / 2 )^2:} / {:(1 / 6)^0 – 12 cdot 3 ^{:-3:}:}`
Υπολογίστε: `{:(-2)^2-2^2+3:} / {:3 cdot (-3 +4)^2 cdot {:{:-3^3+3^3-4:} / {:2 cdot 4+3^2:}:}:}`
Να κάνετε τις πράξεις:
  1. `({:1 / 2:})^2 - 3 cdot (-{:1 / 3:}+{:2 / 6:})^2`
  2. `(-{:4 / 3:}) cdot ( {:4 / 6:})^2+{:3 / 6:}`
  3. `-5 cdot ( - (- {:3 / 2:})^3)+{:4 / 2:} : {:5 / 4:}`
Να κάνετε τις πράξεις: `Α={:{:-1+{:1 / 2:}:}/{:4-{:2 / 3:}:}:}-{:{:({:1 / 3:}-1):(-2) :}/{:({:1/5:}+2):(-5):}:}-( -4):{:{:1/5:}:} `
