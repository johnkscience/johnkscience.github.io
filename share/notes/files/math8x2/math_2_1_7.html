1. Βασικές Πράξεις και Έννοιες

Μάθημα 6 – Αναλογίες

Να απαντήσετε στις παρακάτω ερωτήσεις:
  1. Τι ονομάζουμε λόγο;
  2. Τι είναι η αναλογία;
  3. Να γράψετε τις ιδιότητες των αναλογιών.
Να αποδείξετε τις παρακάτω σχέσεις:
  1. `(2 / 3)=( 4 / 6 ) iff 2 cdot 6 = 3 cdot 4 `
  2. `(2 / 3)=( 4 / 6 ) iff 6 / 3 = 4 / 2`
  3. `(2 / 3)=( 4 / 6 ) iff 2 / 4 = 3 / 6`
  4. `(2 / 3)=( 4 / 6 ) iff (2+3) / 3 = (4+6) / 6`
  5. `(2 / 3)=( 4 / 6 ) iff (2-3) / 3 = (4-6) / 6`
  6. `(2 / 3)=( 4 / 6 ) iff (2) / (3+2) = (4) / (6+4)`
  7. `(2 / 3)=( 4 / 6 ) iff (2) / (3-2) = (4) / (6-4)`
Να αποδείξετε τις παρακάτω σχέσεις:
  1. `(2 / 3)=( 4 / 6 ) = (2+4) / ( 3+6 )`
  2. `(4 / 5)=( 12 / 15 ) = (4+12) / ( 5+15 )`
Να συμπληρώσετε τις παρακάτω σχέσεις:
  1. `2 / 3= 4 / 6 iff 2 cdot 6 = 3 cdot ... `
  2. `2 / 3= 4 / 6 iff 6 / 3 = ... / 2`
  3. `2 / 3= 4 / 6 iff 2 / ... = 3 / 6`
  4. `2 / 3= 4 / 6 iff (2+ ... ) / 3 = (4+6) / ...`
  5. `2 / 3= 4 / 6 iff (2-3) / 3 = (4- ... ) / 6`
  6. `2 / 3= 4 / 6 iff ... / (3+2) = (4) / (6+4)`
  7. `... / 3= 4 / 6 iff (2) / (3-2) = (4) / (6-4)`
Τι είναι τα ισοδύναμα κλάσματα;
Ποια από τα παρακάτω κλάσματα είναι ισοδύναμα;
  1. `2 / 3, 10 / 15`
  2. `2 / 7, 3 / 21`
  3. `4 / 3, 8 / 6, 12 / 9 `
  4. `7 / 3, 14 / 6`
Με την βοήθεια των ισοδύναμων κλασμάτων `2 / 3, 4 / 6` να κατασκευάσετε άλλα ζεύγη ισοδύναμων κλασμάτων.
Με την βοήθεια του κλάσματος `2 / 3` να κατασκευάσετε άλλα ισοδύναμα κλάσματα.
