1. Βασικές Πράξεις και Έννοιες

Μάθημα 1 – Βασικές Πράξεις

Να απαντήσετε στις παρακάτω ερωτήσεις:
  1. Τι ονομάζουμε θετικούς και τι αρνητικούς αριθμούς;
  2. Πώς γίνεται η πρόσθεση;
  3. Πώς γίνεται η αφαίρεση;
Να κάνετε τις πράξεις:
  1. `3+5`
  2. `-3+5`
  3. `3-5`
  4. `-3 -5`
Να κάνετε τις πράξεις:
  1. `2 cdot 5`,
  2. `-2 cdot 5`,
  3. `-2 cdot ( -5)`,
  4. `2 cdot (-5)`
Να κάνετε τις πράξεις:
  1. `2+4+5`,
  2. `2-4+5`,
  3. `-2 -4+5`,
  4. `-2 -4 -5`,
  5. `2+4 -5`
Να κάνετε τις πράξεις:
  1. `(1 / 2) cdot (3 / 4)`,
  2. `(2 / (-4)) cdot ((-5) / (-4))`
Να κάνετε τις πράξεις:
  1. `(1 / 2) + (3 / 4)`,
  2. `1 / 2 – 3 / 5`
  3. `5 / 3 – 4 / 6 -4 / 9`
Να κάνετε τις πράξεις με την βοήθεια της επιμεριστικής ιδιότητας.
  1. `2(3 +4)`,
  2. `-2(3+4)`
  3. `-2( -3 +4)`
  4. `-2 ( -3 -4)`
Να κάνετε τις πράξεις με την βοήθεια της επιμεριστικής ιδιότητας.
  1. `2(3 -4)`,
  2. `(-2 +3)( 1 -2)`,
  3. `(2 -3)( -2 -3 +4)`
Να κάνετε τις πράξεις με την βοήθεια της επιμεριστικής ιδιότητας.
  1. `2(3 -4)`,
  2. `(-2 +3)( 1 -2)`,
  3. `(2 -3)( -2 -3 +4)`
Να κάνετε τις πράξεις με την βοήθεια της επιμεριστικής ιδιότητας.
  1. `1 / 2 ( 3 / 4 + 1 / 2 )`,
  2. `- (1 / 3) ( -(2 / 6) +(3 / 9) )`
  3. ` (- (1 / 3) +(3 / 5) ) ( 2 / 7 – (1 / 3) )`
Ποια είναι η προτεραιότητα των πράξεων;
Να κάνετε τις πράξεις με την σωστή σειρά
  1. `2 cdot 5 – 3 ( 5 -6)`
  2. `2 cdot (-3) - (-4) cdot (-3)`
  3. `-3 cdot ( -4) - [ (-2 +3 cdot (-2)) -6]`
  4. `[(-1) (-2) (-3)] + [-1-2-3]`
